# 赛博孔明 · 数字幕府

把腾讯文档里那套「AI 数字员工团队」方法论，落成一套可用的工作台 + 可直接粘贴的岗位档案。

## 两个入口

| 用途 | 地址 |
|---|---|
| 在线使用（手机/电脑直接打开） | https://kakafeng.github.io/kongming-workshop/ |
| 源码仓库 | https://github.com/kakafeng/kongming-workshop |

手机打开后：浏览器菜单 → 分享 → 添加到主屏幕，就是一个 App。

## 组织架构（14 个工位 / 5 个部门）

| 层 | 部门 | 岗位 |
|---|---|---|
| 中枢 | Hub | 小灯 · 贴身助理（DOT，唯一对接入口） |
| 01 | 幕僚室 | 军师 · 战略官 ／ 主簿 · COO ／ 司仓 · 财务官 ／ 监军 · 反调官 |
| 02 | 内容 Studio | 掌书记 · 主笔 ／ 候风 · 选题官 ／ 丹青 · 设计师 ／ 校书 · 知识官 ／ 行人 · 分发官 |
| 03 | 旅游业务组 | 都尉 · 产品经理 ／ 算曹 · 计调 ／ 典客 · 客服官 |
| 04 | 生活层 | 辩士 · 表达教练 |

每个岗位都带：使命、职责、职责边界、**可直接复制的系统提示词**、知识库、技能库、记忆、OKR、token 消耗、周报。

## 四个功能模块

1. **工位墙** — 14 张工位卡，点开就是完整档案；顶部「今天要处理」自动列出逾期、今日到期、3 天内的事项，一键推进状态。
2. **架构** — 三层纵向结构，看清谁向谁汇报、哪层在烧多少 token。
3. **看板** — 待派工 → 进行中 → 待验收 → 已完成，四列流转；完成的任务点「复盘」，三段式复盘结论可直接写进规则。
4. **周报 · 规则** — 全员 OKR 进度与本周周报；复盘沉淀下来的规则库，才是这套系统真正会长大的地方。

## 数据

- 数据存在浏览器本地（localStorage，key `wb_kongming_workshop_v1`），刷新和关机都不丢。
- 首屏「导出 JSON 备份 / 导入恢复」可跨设备迁移，导入不限条数。
- 「导出全部档案」一键下载全部岗位 Markdown，可直接喂给任意 AI 当人设。

> 注意：GitHub Pages 是静态托管，不同设备之间不会自动同步。换设备时用导出的 JSON 恢复一次即可。

## 怎么让它们真的上工

1. 先只启用三个岗：**监军（反调官）+ 掌书记（执行岗）+ 一套复盘机制**。
2. 把「监军」的系统提示词粘到 AI 会话开头，让它先挑你的方案。
3. 跑通这个闭环：**下达任务 → 验收 → 复盘 → 写进规则**。
4. 闭环稳了，再按缺口逐个扩编——一次上十四个，只会得到十四个不听话的实习生。
